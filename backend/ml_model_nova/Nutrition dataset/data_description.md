# Data Dictionary

| Column | Description |
|--------|-------------|
| `product_name` | Name of the food product |
| `energy-kcal_100g` | Energy in kilocalories per 100g |
| `energy_100g` | Energy in kilojoules per 100g |
| `fat_100g` | Total fat per 100g |
| `saturated-fat_100g` | Saturated fat per 100g |
| `carbohydrates_100g` | Total carbs per 100g |
| `sugars_100g` | Total sugars per 100g |
| `fiber_100g` | Dietary fiber per 100g |
| `proteins_100g` | Protein per 100g |
| `salt_100g` | Salt content per 100g |
| `sodium_100g` | Sodium content per 100g |
| `nutrition-score-fr_100g` | French Nutri-Score (lower is healthier) |
| `nova-group_100g` | NOVA food processing group (1 to 4) |
