# Cleaned Nutrition Dataset (OpenFoodFacts)

This dataset is a cleaned and structured version of the OpenFoodFacts database. It includes nutritional values per 100g for thousands of food products globally.

## 💡 Features Selected

- `product_name`
- `energy-kcal_100g`
- `fat_100g`
- `saturated-fat_100g`
- `carbohydrates_100g`
- `sugars_100g`
- `fiber_100g`
- `proteins_100g`
- `salt_100g`
- `sodium_100g`
- `nutrition-score-fr_100g`
- `nova-group_100g`

## 📚 Use Cases

- Machine learning models (DNN, classification, clustering)
- Risk score prediction
- Personalized nutrition and diet recommendation
- Public health and food transparency analysis

## 📦 Source

Original raw data: [OpenFoodFacts](https://world.openfoodfacts.org/data)
